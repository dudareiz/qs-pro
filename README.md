# Projeto  Qualidade de Software

## Estrutura

- frontend-biblioteca -> React/Vite
- biblioteca-backend -> Spring Boot/Maven
- .github/workflows/ci.yml -> Pipeline GitHub Actions

## Rodando Backend

```bash
cd biblioteca-backend
./mvnw spring-boot:run
```

## Rodando Frontend

```bash
cd frontend-biblioteca
npm install
npm run dev
```
