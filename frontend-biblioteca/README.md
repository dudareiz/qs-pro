# Gerenciador de Biblioteca Pessoal - Frontend

## Tecnologias
- React
- TypeScript
- Vite
- Axios

## Como executar o projeto

### 1. Descompacte o arquivo ZIP

Extraia o projeto em uma pasta de sua preferência.

### 2. Instale as dependências

```bash
npm install
```

### 3. Execute o projeto

```bash
npm run dev
```

### 4. Backend

O backend Spring Boot deve estar rodando em:

```bash
http://localhost:8080
```

## Estrutura do Projeto

- src/componentes
- src/hooks
- src/contextos
- src/paginas
- src/servicos
- src/tipos

## Funcionalidades

- Cadastro de usuários
- Login
- Listagem de livros
- Cadastro de livros
- Edição de livros
- Remoção de livros
- Feedback visual
- Responsividade
- Testabilidade com data-testid
